PES 2021 Manager

Aplicativo desktop feito em Python (Tkinter) para gerenciar elencos e dados de jogadores do PES 2021.

O que ele faz:
Cadastro e edição de jogadores e times, com interface organizada em abas
Visualização de bandeiras dos países por jogador/time
Histórico de alterações: registra criação, edição e transferência de jogadores
Filtro de busca de jogadores por liga
Assistente por chat integrado, usando a API da Anthropic (Claude), com contexto do elenco atual
Compilação para executável Windows (.exe) via PyInstaller

Tecnologias usadas:
Python
Tkinter (interface gráfica)
Pillow (PIL) — tratamento de imagens
PyInstaller — geração do executável
API da Anthropic (Claude) — assistente por chat

Sobre o projeto:
Este projeto foi desenvolvido por conta própria, com apoio de ferramentas de IA generativa, como forma de aprender programação na prática.
